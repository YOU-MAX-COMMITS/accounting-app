# 智能记账本 · PWA 安装包

这是「智能记账本」的可安装版本。上传到任意静态托管后，用手机浏览器打开链接，即可「添加到主屏幕」，像 App 一样使用（全屏、有图标、断网也能记账）。

## 目录结构

```
app/
├── index.html              # 应用主体（全部功能 + 界面）
├── manifest.webmanifest    # 应用名称 / 图标 / 启动方式
├── sw.js                   # Service Worker，离线缓存
└── icons/                  # 桌面图标（192 / 512 / 180 / 32）
```

## 部署（任选一种，都是免费）

### 方式一：GitHub Pages（推荐，最稳）
1. 新建一个仓库，把 `app/` 里的**所有文件**上传到仓库根目录
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main` / 目录选 `/ (root)` → Save
3. 等 1 分钟，得到地址 `https://你的用户名.github.io/仓库名/`
4. 手机浏览器打开该地址

### 方式二：Vercel / Cloudflare Pages
- 把 `app/` 目录直接拖进 Vercel 或 Cloudflare Pages 的部署面板即可，无需构建命令（纯静态）

### 方式三：任意自己的服务器 / 对象存储
- 把 `app/` 下文件传到网站目录即可
- **必须是 HTTPS**（`localhost` 除外），否则「安装到桌面」和离线缓存都不会生效

### 本地先试一下
```bash
cd app
python3 -m http.server 8080
# 电脑浏览器打开 http://localhost:8080
```

## 手机上安装

- **安卓 / Chrome、Edge、华为浏览器**：打开链接后，页面右上角会出现「📲 安装到桌面」按钮，或点浏览器菜单 →「安装应用 / 添加到主屏幕」
- **iPhone / Safari**：点底部「分享」按钮 → 向下找「添加到主屏幕」→ 添加
- 安装后桌面出现图标，点开是全屏无地址栏的独立窗口

## 数据说明（重要）

- 所有数据保存在**本机浏览器本地**（localStorage），不上传任何服务器，换手机/换浏览器不会自动同步
- 每个使用者各自的数据互相独立
- 通过「📥 导出」可备份为 JSON 文件，换设备时用「📤 导入」恢复
- **注意**：换域名部署会导致数据「看不到」（因为存储跟着域名走）。如果从本地 HTML 文件迁移过来，请先在旧页面点「导出」，再到新 App 里点「导入」

## 更新版本

改完 `index.html` 后重新上传即可。若手机打开还是旧界面，属于缓存未更新：可在 `sw.js` 里把 `CACHE_NAME` 改成 `accounting-app-v2` 再上传，用户下次打开会自动拉到新版。
